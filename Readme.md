# Portfólio Pessoal

Projeto desenvolvido na **Agenda 15 -- Desenvolvimento de Sistemas I**,
com o objetivo de apresentar informações profissionais, tecnologias
estudadas e projetos realizados durante a formação em Desenvolvimento de
Sistemas.

## Sobre o projeto

O site é um portfólio pessoal criado com HTML e Bootstrap. A página
reúne informações sobre o perfil profissional, conhecimentos em
tecnologia, projetos desenvolvidos e formas de contato.

## Funcionalidades e seções

-   **Menu de navegação:** permite acessar as seções Perfil, Projetos e
    Contato.
-   **Carousel:** área de destaque com imagens.
-   **Perfil:** apresentação profissional e informações pessoais.
-   **Tecnologias e ferramentas:** exibição das tecnologias estudadas.
-   **Projetos:** apresentação de trabalhos por meio de cards com
    imagem, título e descrição.
-   **Contato:** links para e-mail, GitHub e LinkedIn.
-   **Rodapé:** identificação do projeto e das tecnologias utilizadas.

## Tecnologias utilizadas

-   HTML5 -- estrutura da página.
-   Bootstrap 5.3.3 -- layout, componentes e responsividade.
-   Devicon -- ícones das tecnologias.
-   CSS -- ajustes visuais e personalização.

## Estrutura de pastas

``` text
portfolio/
├── index.html
├── README.md
└── imagens/
    ├── slide1.png
    ├── slide2.png
    ├── slide3.png
    ├── perfil.png
    ├── p1.png
    ├── p2.png
    └── p3.png
```

As imagens listadas são exemplos de nomes utilizados na estrutura do
projeto. Mantenha na pasta `imagens` os arquivos realmente utilizados no
seu site e confira se os nomes correspondem aos caminhos informados no
HTML.

## Como executar o projeto

1.  Baixe ou clone este repositório.
2.  Abra a pasta do projeto no Visual Studio Code.
3.  Confira se o arquivo `index.html` e a pasta `imagens` estão no mesmo
    diretório.
4.  Abra o arquivo `index.html` em um navegador para visualizar o
    portfólio.

O Bootstrap e o Devicon são carregados por links externos; por isso, é
necessário estar conectado à internet para que esses recursos sejam
exibidos corretamente.

## Publicação

O projeto pode ser publicado gratuitamente pelo **GitHub Pages**:

1.  Envie os arquivos do projeto para um repositório no GitHub.
2.  Acesse **Settings \> Pages**.
3.  Em *Build and deployment*, selecione a opção de publicação por uma
    branch.
4.  Escolha a branch `main` e a pasta `/ (root)`.
5.  Clique em **Save** e aguarde a publicação.
